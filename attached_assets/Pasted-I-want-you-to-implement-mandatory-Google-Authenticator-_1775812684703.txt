This is not optional. Any admin account must complete 2FA setup and must pass 2FA verification before being fully logged in or allowed to access admin-protected areas.

Requirements:

1. Scope
- Apply 2FA only to admin users
- Keep the current login flow unchanged for normal users
- Admin users must not be able to bypass 2FA

2. Technology
- Use TOTP compatible with Google Authenticator
- Use `speakeasy` for secret generation and token verification
- Use `qrcode` to generate a QR code for setup

3. Database changes
- Add fields to the user model for:
  - `twoFactorEnabled` (boolean)
  - `twoFactorSecret` (string, nullable until setup)
- If useful, also add:
  - `twoFactorSetupCompletedAt`
  - `twoFactorLastVerifiedAt`

4. Admin login flow
- Admin enters username + password

  - return a response that requires 2FA setup
  - generate a TOTP secret
  - store the secret temporarily or persist it safely for setup
  - return a QR code and manual setup key
- Admin scans the QR with Google Authenticator
- Admin enters the 6-digit code
- Verify the code
- Only after successful verification:
  - mark 2FA as enabled
  - allow full login / session completion

5. Admin login after setup
- After username + password succeeds for an admin with 2FA enabled:
  - do not complete login immediately
  - require a valid 6-digit TOTP code
- Only after correct TOTP verification:
  - issue the final authenticated session/cookie
  - allow access to admin routes

6. Security requirements
- Do not expose the TOTP secret after setup except for the initial setup screen
- Keep the secret stored securely
- Do not allow admin session creation before 2FA passes
- Make sure server-side middleware/admin route protection respects full 2FA completion
- Handle invalid or expired codes safely
- Add rate limiting for 2FA verification attempts
- Add audit log entries for:
  - 2FA setup started
  - 2FA setup completed
  - 2FA verification success
  - 2FA verification failure

7. Frontend requirements
- Add the necessary UI flow for admin users:
  - 2FA setup screen with QR code
  - manual secret key display

8. API requirements

- initiate 2FA setup
- verify initial setup code

- changed files
