==================================================
7. CORE BUSINESS LOGIC
==================================================

A) INSTAGRAM ACCOUNT ASSIGNMENT
- Only admin can create Instagram accounts
- Each Instagram account belongs to exactly one user
- User can only see accounts assigned to them

B) DAILY ENTRY FLOW
- User logs in
- User sees assigned Instagram accounts
- For each assigned account, user can add one or more reels links for a selected day
- User can save as draft or submit the day as completed

C) DAILY ENTRY RULES
- Entries are expected daily
- 1-2 days delay can happen sometimes and is acceptable
- More than 2 days delay must be clearly flagged for admin visibility
- End-of-month bulk backfilling is NOT acceptable
- If someone leaves many days empty and later adds many links at once, admin must detect it easily

D) DUPLICATE RULE
- Same reels URL cannot be inserted twice

E) HISTORY RULE
- No hard deletion of historical records
- Keep logs and timestamps for everything important

8. REELS URL VALIDATION
==================================================

or
- instagram.com/reels/

Reject invalid formats.

Normalize URLs before saving if reasonable.

==================================================
9. DELAY & BULK ENTRY DETECTION
==================================================

Implement automatic detection logic.

DELAY DETECTION:
- If content_date is 1 day behind -> note as 1-day delay
- If 2 days behind -> note as 2-day delay
- If more than 2 days behind -> clear flag

BULK ENTRY DETECTION:
Flag suspicious behavior such as:
- many past-date entries created in one session
- too many backfilled items within a short time
- obvious end-of-month mass entry behavior

Store results in delay_flags table.

In admin UI, show a behavior summary for each user such as:
- normal
- often delayed
- 2+ days delayed
- bulk entry suspected
- needs attention

This is important because the system may be used with 100+ users.

TRC20 VALIDATION:
Use strict validation:
- must start with T
- must be 34 characters
- must match regex:

^T[1-9A-HJ-NP-Za-km-z]{33}$

If invalid, reject input with a clear error message.

Every wallet change must:
- create a wallet history log
- update wallet status
- create an audit log
